# Exam Guard URL Trigger v2.3 (Proctor Timer & Anti-Cheat Edition)

ส่วนขยาย Chrome Extension สำหรับเปิดระบบคุมสอบอัตโนมัติ (Anti-Cheat) เฉพาะ URL ข้อสอบที่กำหนด พร้อมระบบ **นับเวลาถอยหลังการสอบ**, **ระงับการสอบทันทีเมื่อทำผิดกฎครบกำหนด**, และ **แดชบอร์ดระบุตัวตนผู้ทำผิดกฎอย่างชัดเจน**

---

## ฟีเจอร์หลัก (Key Features)

### 1. ระบบจำกัดเวลาสอบและนับถอยหลัง (Exam Timer & Auto Time's Up) ⏱️ [ใหม่ใน v2.3]
- **วิดเจ็ตจับเวลาลอยบนหน้าจอ (Floating Timer Bar)**: แสดงเวลาที่เหลือแบบเรียลไทม์ `⏱️ เวลาที่เหลือ: HH:MM:SS` ตรงกึ่งกลางด้านบนหน้าจอ
- **การแจ้งเตือนตามช่วงเวลาสำคัญ**:
  - เมื่อเหลือ 15 นาที: เปลี่ยนเป็นสีส้ม พร้อมแจ้งเตือน Toast
  - เมื่อเหลือ 5 นาที: เปลี่ยนเป็นสีแดงกะพริบแจ้งเตือนล่วงหน้า
  - เมื่อเหลือ 1 นาที: แจ้งเตือนฉุกเฉินให้เตรียมส่งข้อสอบ
- **ระบบทนต่อการรีเฟรชหน้าจอ (Anti-Refresh Persistence)**: เวลาคำนวณจาก `startTime + ระยะเวลาสอบ` จริงในระบบ แม้นักเรียนกด F5 รีเฟรช เวลาก็จะไม่รีเซ็ตกลับไปเริ่มต้น
- **หน้าจอล็อกดาวน์เมื่อหมดเวลา (Time's Up Screen)**:
  - เมื่อเวลาหมดลง หน้าจอจะถูกล็อกทันที ไม่สามารถพิมพ์หรือแก้ไขข้อสอบได้
  - ผู้คุมสอบสามารถใช้ **รหัส PIN** เพื่อ **เพิ่มเวลาสอบฉุกเฉิน (+5, +10, +15 นาที)** ให้นักเรียนได้ทันที

### 2. ปรับปรุงระบบตรวจจับการคัดลอกไม่ให้นับความผิดเร็วเกินไป 🛡️ [แก้ไขใน v2.3]
- **การลากคลุมข้อความ (Select Text)**: บล็อกการลากคลุมข้อความและปิดกั้นการเลือก แต่ **ไม่ตัดสิทธิ์เป็นความผิด** เพื่อป้องกันนักเรียนเผลอคลิกลากเมาส์แล้วโดนตัดสิทธิ์ทันที
- **ป้องกันการนับความผิดซ้ำซ้อน (De-duplication)**: เมื่อกด `Ctrl+C` ระบบจะนับเป็นความผิดเพียง 1 ครั้ง และไม่นับซ้ำกับเหตุการณ์ `copy` ของเบราว์เซอร์
- **ป้องกันการกดปุ่มค้าง (Key Repeat Protection)**: การกดปุ่ม `Ctrl+C` ค้างไว้จะไม่ถูกนับรัวๆ อีกต่อไป
- **ระบบ Cooldown**: มีการหน่วงเวลา 2.5 วินาทีต่อการพยายามคัดลอกแต่ละครั้ง เพื่อให้นักเรียนมีเวลาตระหนักและหยุดการกระทำโดยไม่ถูกตัดสิทธิ์ใน 1 วินาที

### 3. ระบบหยุดการสอบทันทีเมื่อละเมิดครบกำหนด (Exam Termination & Lockdown) ⛔
- เมื่อผู้สอบทำผิดกฎสะสมครบตามจำนวนที่กำหนด (ค่าเริ่มต้น 3 ครั้ง หรือตามที่ตั้งไว้):
  - **แสดงหน้าจอล็อกดาวน์เต็มจอ (Lockout Screen)** ปิดกั้นการมองเห็นและการมีปฏิสัมพันธ์กับข้อสอบ 100%
  - ปิดกั้นการเลื่อนหน้าจอ (Scroll Lock) และปิดกั้นการคลิก พิมพ์ หรือกดส่งข้อสอบ
  - ดึงผู้สอบออกจากโหมด Fullscreen และบังคับตัดสิทธิ์
  - **ป้องกันการกด F5 รีเฟรชเพื่อหลบเลี่ยง**: ระบบจำสถานะใน Storage ทันทีที่หน้ารีโหลดจะล็อกหน้าจอทันที
  - **ระบบป้องกันการลบโค้ด (Anti-Tamper MutationObserver)**: ป้องกันการพยายามลบกล่องล็อกดาวน์ผ่าน DevTools
  - มีช่องทางให้ **อาจารย์ผู้คุมสอบกรอกรหัส PIN (ค่าเริ่มต้น: 1234)** เพื่อปลดล็อกในกรณีมีเหตุสุดวิสัย

### 4. ระบบระบุตัวตนและแสดงผู้ละเมิดกฎ (Examinee Identification & Audit Logs) 👤
- **ก่อนเริ่มสอบ (Start Gate)**: บังคับให้นักเรียนกรอก:
  - ชื่อ - นามสกุล
  - รหัสประจำตัวนักเรียน/นักศึกษา
  - ห้องสอบ / เลขที่นั่ง
- **ลายน้ำระบุตัวตน (Anti-Photo Watermark)**: แสดงชื่อและรหัสนักศึกษาลอยบนหน้าจอและเป็นลายน้ำจางๆ ทั่วพื้นหลัง ป้องกันการใช้สมาร์ทโฟนแอบถ่ายหน้าจอ
- **Extension Popup**:
  - แสดงเวลาสอบที่เหลือของแท็บปัจจุบัน
  - แสดงกล่องแจ้งเตือนสีแดงเด่นชัด **"🚨 พบผู้ทำผิดกฎเกินกำหนด!"** พร้อมระบุชื่อและรหัสนักศึกษาทันที
  - แสดงสถิติรวม: ผู้สอบทั้งหมด, กำลังสอบ, ระเมิดเกินกำหนด
- **แดชบอร์ดผู้คุมสอบ (Proctor Dashboard - ในหน้า Options)**:
  - ตารางสรุปรายชื่อผู้เข้าสอบทั้งหมด พร้อมตัวกรองดูเฉพาะผู้ที่หมดเวลาสอบ หรือผู้ที่ละเมิดเกินกำหนด
  - **ดูบันทึกเหตุการณ์ฉบับเต็ม (Audit Timeline Modal)**: ดูรายการความผิดทุกครั้งแบบเรียงตามเวลา
  - **ปุ่มส่งออกรายงาน (Export CSV)**: ดาวน์โหลดสรุปรายชื่อและประวัติการละเมิดส่งให้อาจารย์เป็นหลักฐาน

## การติดตั้ง (Installation)

1. เปิดเบราว์เซอร์ Google Chrome แล้วไปที่ `chrome://extensions`
2. เปิดสวิตช์ **Developer mode** (มุมขวาบน)
3. คลิกปุ่ม **Load unpacked** (โหลดส่วนขยายที่คลายการบีบอัดแล้ว)
4. เลือกโฟลเดอร์นี้ (`exam-guard-url-trigger-v2-fixed`)

---

## วิธีใช้งานและการตั้งค่า (Usage & Settings)

1. คลิกที่ไอคอน **Exam Guard** บน Toolbar ของ Chrome หรือคลิกขวาเลือก **Options**
2. ในแท็บ **⚙️ ตั้งค่าระบบ**:
   - **URL รูปแบบข้อสอบ**: ใส่ URL เช่น `https://exam.example.com/exam/*` (หนึ่ง URL ต่อหนึ่งบรรทัด)
   - **ระบบตั้งเวลาสอบ**:
     - เปิดใช้งานระบบจำกัดเวลาสอบ (Countdown Timer)
     - ระบุระยะเวลาสอบ เช่น `60` นาที
   - **จำนวนการละเมิดสูงสุด**: กำหนดได้ระหว่าง 1 - 20 ครั้ง (ค่าเริ่มต้น 3 ครั้ง)
   - **รหัส PIN ผู้คุมสอบ**: สำหรับปลดล็อกหน้าจอ/เพิ่มเวลาฉุกเฉิน (ค่าเริ่มต้น `1234`)
3. คลิก **"บันทึกการตั้งค่า"**

## วิธีทำให้ "หน้าเว็บข้อสอบ" ตรวจจับและบล็อกผู้ที่ไม่ได้ติดตั้งส่วนขยายอัตโนมัติ 🚀 [ใหม่!]

หากต้องการให้ **หน้าเว็บข้อสอบ** บล็อกคนที่ไม่ได้ติดตั้งส่วนขยายทันที (เช่น เปิดใน Edge, Safari, เปิดในมือถือ หรือปิดส่วนขยายไว้):

### ขั้นตอนการนำไปใช้:
นำไฟล์ `exam-guard-detector.js` ไปวางไว้ในโปรเจกต์เว็บข้อสอบของคุณ แล้วใส่โค้ดบรรทัดนี้ลงใน `<head>` หรือ `<body>` ของหน้าข้อสอบ:

```html
<!-- วางโค้ดนี้ในหน้าเว็บข้อสอบ -->
<script src="exam-guard-detector.js"></script>
```

### การทำงานอัตโนมัติ:
1. **เมื่อนักเรียนเปิดผ่าน Chrome ที่มี Exam Guard**:
   - ระบบจะผ่านการตรวจสอบ (Handshake ผ่าน) ภายในเสี้ยววินาที และแสดงหน้าข้อสอบตามปกติ
2. **เมื่อนักเรียนเปิดผ่านเครื่องที่ "ไม่มี Exam Guard"**:
   - หน้าจอจะถูกบล็อก 100% ทันที พร้อมแสดงหน้ากากแจ้งเตือนสีแดง:
     `⛔ ไม่อนุญาตให้เข้าทำข้อสอบ: ตรวจไม่พบส่วนขยาย Exam Guard บนเบราว์เซอร์ของคุณ`
   - ข้อสอบทั้งหมดจะถูกซ่อนไว้ ไม่สามารถแอบดูหรือทำข้อสอบได้จนกว่าจะติดตั้งส่วนขยาย

### หน้าเว็บตัวอย่างสำหรับทดสอบ:
สามารถเปิดไฟล์ `demo-exam-page.html` เพื่อทดสอบระบบได้ทันที:
- ลองเปิดใน **Chrome ที่เปิด Exam Guard** -> จะเข้าทำข้อสอบได้ปกติ
- ลองเปิดใน **Microsoft Edge** หรือ **โหมด Incognito** -> หน้าเว็บจะบล็อกทันที!

## 🌟 โซลูชันที่ 2: Exam Guard Web (Zero Extension Edition - คนอื่นไม่ต้องลงอะไรเลย!) 🎉

หากคุณ **ไม่อยากให้ผู้สอบ/นักเรียนต้องติดตั้งส่วนขยาย Chrome** (เช่น อยากให้เปิดสอบได้ทุกอุปกรณ์ทั้ง Mac, iPad, iPhone, Android, แท็บเล็ต, PC, หรือเบราว์เซอร์ใดๆ โดยนักเรียนไม่ต้องกดติดตั้งอะไรให้ยุ่งยาก):

คุณสามารถใช้ไฟล์ **`exam-guard-web.js`** ฝังลงในหน้าเว็บข้อสอบของคุณโดยตรง!

### 1. วิธีนำไปใช้งาน (ง่ายมาก เพียง 1 บรรทัด)
นำไฟล์ `exam-guard-web.js` ไปวางไว้ในโฟลเดอร์เดียวกับเว็บข้อสอบ แล้วแทรกโค้ดนี้ในหน้าข้อสอบ:

```html
<script src="exam-guard-web.js"></script>
```

หรือหากต้องการปรับแต่งเวลาสอบและจำนวนครั้งที่อนุญาตให้ละเมิด:
```html
<script>
  window.ExamGuardConfig = {
    examTitle: "แบบทดสอบปลายภาควิชาคอมพิวเตอร์",
    examDurationMinutes: 60,   // ระยะเวลาสอบ (นาที)
    maxViolations: 3,          // จำนวนครั้งที่ทำผิดกฎได้สูงสุดก่อนถูกตัดสิทธิ์
    proctorPin: "1234",        // รหัส PIN ครูผู้คุมสอบ (ใช้ปลดล็อก หรือเพิ่มเวลา)
    requireStudentInfo: true   // บังคับกรอกชื่อและรหัสนักศึกษาก่อนเริ่มสอบ
  };
</script>
<script src="exam-guard-web.js"></script>
```

### 2. ฟีเจอร์ที่ทำงานอัตโนมัติบนหน้าเว็บ (โดยไม่ต้องมี Extension):
1. **หน้าต่างลงทะเบียนก่อนเริ่มสอบ (Start Gate)**: ให้นักเรียนกรอกชื่อ-นามสกุล, รหัสนักศึกษา, และเลขที่นั่ง
2. **บังคับโหมดเต็มหน้าจอ (Auto Fullscreen)**: ทันทีที่กดเริ่มสอบ ระบบจะขยายเต็มจอ
3. **วิดเจ็ตนับเวลาถอยหลังลอยบนหน้าจอ (Floating Countdown Timer)**: แจ้งเตือนเมื่อเหลือ 15, 5, 1 นาที และล็อกหน้าจอเมื่อหมดเวลา
4. **ลายน้ำป้องกันการแอบถ่ายหน้าจอ (Anti-Cheat Watermark)**: แสดงชื่อและรหัสนักศึกษาลอยบนมุมจอ และลายน้ำจางๆ ทั่วพื้นหลัง
5. **ระบบป้องกันการโกงครบวงจร**:
   - บล็อกการสลับแท็บ / ย่อเบราว์เซอร์ / เปิดแอปอื่น (Visibility & Blur detection)
   - บล็อกการออกจาก Fullscreen
   - บล็อกการคลิกขวา (Context Menu)
   - บล็อกการคัดลอก (Copy / Cut) พร้อมระบบ Cooldown 2.5s (ป้องกันการกด Ctrl+C แล้วนับรัวๆ)
   - ป้องกันการลากคลุมข้อความ (Select Text)
   - บล็อกคีย์ลัดอันตราย: `Ctrl+C`, `Ctrl+V`, `Ctrl+U`, `Ctrl+S`, `F12`, `PrintScreen`, `Alt+Tab`
6. **ล็อกหน้าจอถาวรเมื่อทำผิดครบกำหนด (Persistent Lockout)**:
   - บันทึกประวัติความผิดพร้อมเวลาลงในเครื่อง (แม้กด F5 รีเฟรช หน้าจอก็ยังคงล็อกเหมือนเดิม!)
   - มีช่องให้อาจารย์กรอก **รหัส PIN (ค่าเริ่มต้น: 1234)** เพื่อปลดล็อกให้นักเรียน
7. **ส่งออกรายงานประวัติการสอบ (Export CSV Report)**:
   - อาจารย์สามารถดาวน์โหลดสรุปผลการเข้าสอบและบันทึกประวัติการละเมิดผ่านคำสั่ง `window.ExamGuardWeb.exportReportCsv()` หรือคลิกปุ่มบนหน้าเว็บได้ทันที
